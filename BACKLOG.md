# Forge Backlog

Problems found during work that were not fixed in the same change. Rule (2026-10-15): every finding is either fixed or recorded here; nothing is skipped. Entries are grouped by area; IDs are stable and never reused.

**This file holds open work only.** When an entry is finished, its row moves to [`BACKLOG-DONE.md`](BACKLOG-DONE.md) in the same change, with the date and `this change` in the `By` column; when that change is merged, `this change` becomes the commit and the pull request (the owner, 2026-11-23). An entry that is partly done stays here and says what is left. `tests/test_backlog.py` holds all of this.

Severity: **High** blocks a planned capability or risks data loss/security; **Med** causes drift, wrong behaviour in edge cases, or significant debt; **Low** cosmetic, cleanup, or documentation.
