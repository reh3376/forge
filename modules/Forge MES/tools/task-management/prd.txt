# Product Requirements Document (PRD): Configurable Enzyme Dosing System

## Executive Summary

The current enzyme dosing system in the WHK Recipe Configuration application has hardcoded enzyme definitions, dosing rates, and calculation logic embedded in the `EnzymeDosingService`. This PRD outlines the requirements to make the enzyme dosing system fully configurable by operations administrators through a database-driven approach that leverages the existing Item entity infrastructure.

## Business Requirements

### Primary Goals
1. **Enable dynamic enzyme management** - Operations admins can add/modify enzymes without code deployments
2. **Integrate with existing item system** - Leverage current Item entities for enzyme identification
3. **Maintain calculation accuracy** - Preserve existing dosing calculation logic while making it configurable
4. **Support audit trails** - Track all configuration changes for compliance
5. **Preserve API compatibility** - Existing recipe generation and dosing endpoints continue to work

### User Stories

**Operations Administrator:**
- As an operations admin, I want to add new enzyme items to the system when we source from new suppliers
- As an operations admin, I want to configure dosing rates and instructions for each enzyme item
- As an operations admin, I want to modify enzyme categories and calculation methods
- As an operations admin, I want to view audit trails of all enzyme configuration changes

**Recipe Developer:**
- As a recipe developer, I want enzyme dosing calculations to use current configured rates automatically
- As a recipe developer, I want to reference enzymes by their existing item numbers in recipes
- As a recipe developer, I want clear error messages when enzyme configurations are missing

**System Administrator:**
- As a system admin, I want to configure global calculation parameters (metric ton divisor, precision)
- As a system admin, I want to enable/disable specific business rules (citric exclusion, etc.)

### 2. Service Layer Refactoring

#### Updated EnzymeDosingService
```typescript
@Injectable()
export class EnzymeDosingService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly systemConfigService: SystemConfigurationService,
    private readonly logger: Logger
  ) {}

  async getEnzymeConfigurationByItemName(itemName: string): Promise<EnzymeConfiguration | null> {
    // Check system configuration for citric exclusion
    const excludeCitric = await this.systemConfigService.getBooleanValue('EXCLUDE_CITRIC_FROM_DOSING', true);
    if (excludeCitric && itemName.toLowerCase().includes('citric')) {
      this.logger.log(`Citric enzyme detected: ${itemName}. Skipping dosing calculation.`);
      return null;
    }

    return await this.prisma.enzymeConfiguration.findFirst({
      where: {
        item: {
          itemName: { equals: itemName, mode: 'insensitive' }
        },
        active: true
      },
      include: {
        item: true,
        calculationRules: { where: { active: true } }
      }
    });
  }

  async calculateEnzymeDosing(
    totalGrainLoadLbs: number,
    mashBill: string,
    enzymeIdentifier: string
  ): Promise<{ dose: number; instructions: string } | null> {
    
    const enzymeConfig = await this.getEnzymeConfigurationByItemName(enzymeIdentifier);
    if (!enzymeConfig) {
      // Try by item number as fallback
      const configByNumber = await this.getEnzymeConfigurationByItemNumber(enzymeIdentifier);
      if (!configByNumber) {
        throw new Error(`Enzyme configuration not found for: "${enzymeIdentifier}"`);
      }
      return this.performCalculation(configByNumber, totalGrainLoadLbs, mashBill);
    }

    return this.performCalculation(enzymeConfig, totalGrainLoadLbs, mashBill);
  }

  private async performCalculation(
    enzymeConfig: EnzymeConfiguration,
    totalGrainLoadLbs: number,
    mashBill: string
  ): Promise<{ dose: number; instructions: string }> {
    const metricTonDivisor = await this.systemConfigService.getNumberValue('METRIC_TON_DIVISOR', 2205);
    const precision = await this.systemConfigService.getNumberValue('ENZYME_CALCULATION_PRECISION', 3);
    
    const mashBillParts = this.parseMashBill(mashBill);
    const dose = await this.calculateDoseByRules(enzymeConfig, totalGrainLoadLbs, mashBillParts, metricTonDivisor);

    return {
      dose: parseFloat(dose.toFixed(precision)),
      instructions: enzymeConfig.instructions
    };
  }
}
```

#### New SystemConfigurationService
```typescript
@Injectable()
export class SystemConfigurationService {
  constructor(private readonly prisma: PrismaService) {}

  async getValue(key: string, defaultValue?: string): Promise<string | null> {
    const config = await this.prisma.systemConfiguration.findUnique({
      where: { key, active: true }
    });
    return config?.value ?? defaultValue ?? null;
  }

  async getNumberValue(key: string, defaultValue?: number): Promise<number> {
    const value = await this.getValue(key);
    return value ? parseFloat(value) : (defaultValue ?? 0);
  }

  async getBooleanValue(key: string, defaultValue?: boolean): Promise<boolean> {
    const value = await this.getValue(key);
    return value ? value.toLowerCase() === 'true' : (defaultValue ?? false);
  }

  async setValue(key: string, value: string, updatedBy: string): Promise<void> {
    await this.prisma.systemConfiguration.upsert({
      where: { key },
      update: { value, updatedBy, updatedAt: new Date() },
      create: { key, value, createdBy: updatedBy }
    });
  }
}
```

### 3. API Layer Updates

#### New EnzymeConfiguration Controller
```typescript
@Controller('enzyme-configurations')
@ApiTags('Enzyme Configurations')
export class EnzymeConfigurationController {
  constructor(private readonly service: EnzymeConfigurationService) {}

  @Get()
  @ApiOperation({ summary: 'List all enzyme configurations' })
  async findAll(@Query() filters: EnzymeConfigurationFiltersDto) {
    return this.service.findAll(filters);
  }

  @Post()
  @ApiOperation({ summary: 'Create enzyme configuration' })
  async create(@Body() data: CreateEnzymeConfigurationDto) {
    return this.service.create(data);
  }

  @Put(':id')
  @ApiOperation({ summary: 'Update enzyme configuration' })
  async update(@Param('id') id: string, @Body() data: UpdateEnzymeConfigurationDto) {
    return this.service.update(id, data);
  }

  @Delete(':id')
  @ApiOperation({ summary: 'Deactivate enzyme configuration' })
  async remove(@Param('id') id: string) {
    return this.service.deactivate(id);
  }
}
```

### 7. Validation & Testing Requirements

#### Data Validation Rules
- Enzyme configuration must reference valid, active Item
- Dose per metric ton must be positive number
- Instructions cannot be empty
- Only one enzyme configuration per item
- Calculation rules must have valid grain types and methods

#### Testing Strategy
- **Unit Tests:** All calculation methods with various scenarios
- **Integration Tests:** Database operations and API endpoints
