# Task ID: 28
# Title: Implement Enzyme Dosing Frontend Application
# Status: pending
# Dependencies: 1, 2, 5, 23, 26
# Priority: high
# Description: Develop a production-grade, mobile-first enzyme dosing frontend application for operators, integrating with the WhiskeyHouse MES and backend APIs to provide real-time enzyme dosing calculations, recipe BOM integration, audit trail, and PWA capabilities.
# Details:
1. Design and implement a responsive, mobile-first UI using Next.js 14+ App Router, Tailwind CSS, and Shadcn/ui components, adhering to the MES UI design system for seamless operator experience.
2. Build a core enzyme dosing calculator form using React Hook Form and Zod for robust validation, supporting mash bill input (XX-XX-XX-XX format) and grain load entry, with real-time calculation updates and error handling.
3. Integrate with the existing enzyme configuration REST API endpoints via React Query for fetching enzyme parameters, recipe BOM data, and submitting calculation/audit records.
4. Implement auto-population of mash bill and grain load fields from selected recipe BOMs, leveraging MES data models.
5. Display calculation results instantly, including required enzyme mass and activity units, with clear unit handling and conversion logic as per backend specifications.
6. Provide calculation history and audit trail views, with filtering and export (CSV/PDF) and print capabilities for compliance and traceability.
7. Ensure full PWA support (offline mode, installability, manifest, service worker) for robust production use.
8. Integrate authentication and session management using the existing Entra ID/MSAL mechanisms, ensuring secure access and session persistence.
9. Adhere to advanced security practices for input validation, error handling, and audit logging as defined in security requirements.
10. Ensure accessibility (WCAG 2.1 AA), performance, and usability standards are met for production environments.

# Test Strategy:
- Write unit and integration tests for all form logic, validation, and calculation flows using the comprehensive testing suite.
- Perform end-to-end tests simulating operator workflows: mash bill entry, recipe BOM selection, calculation, error handling, and audit trail review.

- Test mobile responsiveness, offline/PWA functionality, and print/export features across supported devices and browsers.
