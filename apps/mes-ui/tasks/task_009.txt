# Task ID: 9
# Title: Implement Production Scheduling Interface
# Status: done
# Dependencies: 4, 5
# Priority: high
# Description: Create the production scheduling interface with ERP integration, resource allocation, and timeline visualization for whiskey production workflow (Mashing → Fermentation → Distillation → Barreling), including a three-step Production Order Creation Wizard.
# Details:
1. Design and implement three-panel scheduling interface:
   - Production Orders list with filtering ("View All", "Show Unscheduled")
   - Schedule table with comprehensive columns (Index, Sch Order, Customer, etc.)
   - Order forms with improved UX
2. Create ERP integration for order synchronization
3. Implement recipe-based scheduling with capacity planning, supporting whiskey production terminology:
   - Proof Gallons, Total Barrels calculations
   - Production stage durations tracking
   - Recipe codes (DWL-75-21-00-04-R01 format)
   - Container types and Customer codes
   - Mash Bills (60-40-00-00, etc.)
4. Add resource allocation and optimization
5. Create equipment availability tracking
6. Implement Gantt chart visualization using Recharts or D3.js for the complete production timeline
7. Add schedule conflict detection and resolution
8. Create batch scheduling with dependency management
9. Implement drag-and-drop schedule adjustments
10. Redesign the Edit Scheduled Order modal with improved UX:
    - Organize 28+ fields into logical sections/tabs
    - Implement progressive disclosure for complex data
    - Add auto-calculations for durations and quantities
    - Ensure mobile-responsive design for factory floor devices
11. Implement Production Order Creation Wizard with three steps:
    - Order Details with comprehensive form fields
    - Bill of Materials with recipe integration
    - Milling Bins Configuration for equipment assignment
12. Add recipe-to-production conversion functionality:
    - Recipe selection driving default production parameters
    - BOM conversion from recipe ingredients to production quantities
    - Scaling calculations based on production quantity vs recipe yield
    - Equipment assignment based on recipe requirements
